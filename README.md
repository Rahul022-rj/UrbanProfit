
# UrbanProfit 📊

### AI-Powered Business Location Intelligence & Market Analysis

UrbanProfit is an interactive business intelligence application
designed to help entrepreneurs identify promising business
locations across Indian cities.

## 🚀 Features

- Search and select cities across India.
- Explore business-friendly localities.
- Compare multiple locations.
- Market potential analysis.
- Interactive charts and visualizations.
- Locality-wise market insights.
- Business recommendations such as cafes, restaurants,
  retail stores and other business categories.
- Location comparison with available infrastructure data.
- Nearest metro distance information (where data is available).
- Downloadable market analysis reports.
- Interactive dashboard with a modern UI.

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Machine Learning (if implemented in the project)

## ⚙️ Installation

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project directory:

```bash
cd UrbanProfit
```

3. Create a virtual environment:

```bash
python -m venv venv
```

4. Activate it:

Windows:
```bash
venv\Scripts\activate
```

5. Install dependencies:

```bash
pip install -r requirements.txt
```

6. Run the application:

```bash
streamlit run app.py
```
